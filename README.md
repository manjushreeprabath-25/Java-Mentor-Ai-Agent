# Java Mentor AI Agent

## Overview
Java Mentor AI Agent is an AI-powered voice assistant designed to help learners master Java programming. It was developed using Cursor IDE and ElevenLabs Conversational AI by connecting to the ElevenLabs MCP Server.

## Features
- Voice-based Java learning
- Java fundamentals
- Object-Oriented Programming (OOP)
- Data Structures and Algorithms (DSA)
- Code explanation and debugging
- Interview preparation
- Interactive AI conversations

## Technologies Used
- Cursor IDE
- ElevenLabs Conversational AI
- ElevenLabs MCP Server
- Java
- GitHub
